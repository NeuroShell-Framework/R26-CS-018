%%    §A  AI operating instructions
%%    §B  Standards register   (rule ID -> requirement -> where implemented)
%%    §C  Ambiguities / conflicts in the source guideline + resolution used

%%    §E  USER CONFIGURATION   <- the ONLY block of macros meant to be edited

%% ============================================================================
%%  §A  AI OPERATING INSTRUCTIONS
%% ============================================================================
%%  PURPOSE
%%    This file is both a working template AND a machine-readable specification.
%%    Given a dissertation draft (LaTeX, Word text, Markdown or plain text), an AI
%%    should be able to re-flow it into this template so that it complies with the
%%    SLIIT guideline, and to audit/repair an existing document against §B.
%%
%%  WORKFLOW
%%    1. Read §B, §C, §D completely before changing anything.
%%    2. Work on a COPY. Keep §F byte-for-byte unchanged. (If a rule in §B seems to
%%       require a change in §F, re-read §C first; the choice is probably deliberate.)
%%    3. Fill §E from the draft: title, candidate names + IDs, supervisor, degree,
%%       submission date, switches. Never leave sample values in a deliverable.
%%    4. Map the draft's content onto §G in the REQUIRED COMPONENT ORDER (rule DOC-03).
%%       Keep the author's wording. Change structure and formatting only.
%%       Do NOT invent content, citations, data, names or signatures.
%%       If a mandatory element is missing (abstract, keywords, supervisor, declaration
%%       text, references...) insert  \TODO{what is missing}  and report it.
%%    5. Apply the heading-case rules by hand (see M1 in §D).
%%    6. Replace ad-hoc formatting with the template constructs (see recipes V1-V22 in §D).
%%    7. Compile (latexmk). Resolve every error, "undefined reference", "Citation
%%       undefined" and leftover \TODO warning.
%%    8. Walk through §H. Report to the user: (a) what you changed, (b) what could not
%%       be verified automatically (word counts, page budgets...), (c) remaining TODOs.
%%
%%  HARD CONSTRAINTS FOR THE AI
%%    - Never override margins, fonts, font sizes, line spacing, page-number style or
%%      heading formats in the body. If the draft does so, strip it (recipes in §D).
%%    - Never type numbers by hand ("Figure 3", "Chapter 2", "Table 1.2", page refs).
%%      Use \label / \cref. Never write "the following table/figure".
%%    - Never fake structure with \textbf, \Large, \vspace, \newpage or blank lines.
%%      Use \chapter, \section, \subsection, floats and the macros in §F.
%%    - Never change the meaning of the text while "fixing" it.
%%
%%  RULE TAGS
%%    Code in §F/§G carries tags like  %% [FNT-01]  that point to the rule in §B it
%%    enforces. Searching a tag shows exactly where a rule is implemented.
%%
%% ============================================================================
%%  §B  STANDARDS REGISTER
%% ============================================================================
%%  Source section numbers refer to the SLIIT guideline PDF ("Common Instructions" = 2,
%%  "Components" = 3). Status: AUTO = enforced by this template, MANUAL = see §D,
%%  CHOICE = guideline ambiguous, resolved in §C.
%%
%%  --- DOCUMENT ---------------------------------------------------------------
%%  DOC-01 AUTO    A4 paper, 12 pt base size, single-sided (2.2, 3).
%%  DOC-02 MANUAL  Whole document >= 50 A4 pages (3: "Document Size: Min 50 A4 Pages").
%%  DOC-03 AUTO    Component order (3): [Cover - hard copy only] Title page, Declaration,
%%                 [Dedication], Abstract, Acknowledgement, Table of Contents, List of
%%                 Figures, List of Tables, List of Abbreviations, [List of Appendices],
%%                 1 Introduction, 2 Methodology, 3 Results and Discussion,
%%                 4 Conclusions and Recommendations, Reference List, [Bibliography],
%%                 [Glossary], Appendices.   ("if any" items are switches in §E.)
%%  DOC-04 MANUAL  Page budgets (3): Title 1, Declaration 1, Abstract 1, Acknowledgement 1,
%%                 ToC 1-2, Introduction 10-15, Methodology 15-25, Results & Discussion
%%                 5-10, Conclusion 2-4, References >= 2, Glossary 1-2, Appendices unlimited.
%%  DOC-05 MANUAL  Submission set (2.01): Draft = soft bound, to supervisor for corrections;
%%                 Final = soft copy uploaded to the cloud folder (1 group report +
%%                 4 individual summary reports); hard-bound copy only if wanted.
%%                 Each individual summary report uses this same template and rules.
%%
%%  --- PAGE LAYOUT ------------------------------------------------------------
%%  LAY-01 AUTO    Margins: LEFT 40 mm, BOTTOM 40 mm, TOP 25 mm, RIGHT 25 mm (2.3).
%%  LAY-02 AUTO    Line spacing 1.5 for body text (2.1). SINGLE spacing only for: abstract,
%%                 tables, indented quotations (2.1); reference entries (1.12);
%%                 captions/sources and declaration signature blocks (derived).
%%  LAY-03 AUTO    Every chapter starts on a new page (1.11).
%%
%%  --- FONTS & HEADINGS -------------------------------------------------------
%%  FNT-01 AUTO    Times New Roman everywhere (2.2). pdfLaTeX uses a metric-compatible clone;
%%                 XeLaTeX/LuaLaTeX use the real font when installed (see §F fonts).
%%  FNT-02 AUTO    Chapter heading: ALL CAPITALS, 14 pt, bold (2.2). Type the title normally;
%%                 the template upper-cases it. ToC keeps the typed case.
%%  FNT-03 AUTO*   Section heading: Title Case, 12 pt, bold (2.2).   *size/weight auto,
%%                 case = MANUAL (M1).
%%  FNT-04 AUTO*   Sub-section heading: Sentence case, 12 pt, bold (2.2). *case = MANUAL (M1).
%%  FNT-05 AUTO    Body text 12 pt, sentence case (2.2).
%%  FNT-06 AUTO    Tables/illustrations may use smaller type if legible (2.2): tables use
%%                 \small, single spacing.
%%  FNT-07 AUTO    Numbering depth: chapter (1), section (1.1), sub-section (1.1.1) only.
%%                 Deeper levels are NOT in the guideline - avoid \subsubsection.
%%
%%  --- PAGINATION -------------------------------------------------------------
%%  PAG-01 AUTO    No page number on the cover or the title page (2.03).
%%  PAG-02 AUTO    Preliminary pages: lower-case Roman numerals, centred at bottom; the
%%                 title page is not counted, so Declaration = i (2.03, Appendix II).
%%  PAG-03 AUTO    Body + appendices: Arabic numerals; start at 1 on the first page of
%%                 chapter 1 and continue through the appendices (2.03). Position CHOICE C1.
%%
%%  --- TABLES & ILLUSTRATIONS ------------------------------------------------
%%  ILL-01 AUTO    Tables and figures are centred (2.04).
%%  ILL-02 MANUAL  Every table/figure is cited in the text by NUMBER via \cref (2.04).
%%  ILL-03 AUTO    Numbered with the chapter number: Figure 1.1, Table 2.3 (1.8, 1.9; C5).
%%  ILL-04 AUTO    Figure caption BELOW the figure; table caption ABOVE the table; optional
%%                 "Source:" line below (\sliitsource) (2.04 sample).
%%  ILL-05 MANUAL  Charts/graphs/maps/tables larger than a page go to an appendix (2.04).
%%  ILL-06 MANUAL  Photographs: high quality, colour or B/W; avoid glossy finish and dark
%%                 backgrounds; write "Original in Color" in the caption when colour is
%%                 used -> \OriginalInColor (2.05).
%%
%%  --- FRONT MATTER -----------------------------------------------------------
%%  COV-01 AUTO    Hard cover (FINAL HARD COPY ONLY): black background, gold text; layout per
%%                 Appendix I (\HardCovertrue). Draft/soft copies: no cover.
%%  COV-02 MANUAL  Spine lettering (physical, hard copy): short degree name 80 mm from the
%%                 bottom, year 40 mm from the bottom, candidate name with initials 20 mm
%%                 from the top; all in GOLD (6.3).
%%  TIT-01 AUTO    Title page contents (1.2, Appendix III): title (+subtitle), candidate full
%%                 name(s), student ID(s), "Dissertation submitted in partial fulfillment of
%%                 the requirements for the <official degree name>", department, institute,
%%                 country, month + year. Title ALL CAPS bold 16 pt; other lines 14 pt
%%                 (statement 12 pt); centred; vertical gaps 6/1/3/3/1 lines of 16 pt @1.5.
%%  DEC-01 AUTO    Declaration page (1.3): verbatim candidate declaration + copyright grant,
%%                 signature + date; supervisor certification, signature + date. One page.
%%  ABS-01 AUTO/MANUAL  Abstract (1.4): one page; heading "Abstract" Title Case 12 pt bold;
%%                 text 11 pt single-spaced; <= 300 words (MANUAL); covers intro, method, tests,
%%                 results, conclusions, recommendations (MANUAL); 3-5 keywords (MANUAL).
%%  DED-01 AUTO    Dedication optional (1.5) -> \IncludeDedicationtrue.
%%  ACK-01 MANUAL  Acknowledgement (1.6): help from staff/peers/external bodies (data,
%%                 apparatus, analysis, writing), sponsor/funder name + details, supervisor.
%%  TOC-01 AUTO    Table of Contents (1.7): all chapters + all sub-sections + preliminary
%%                 pages (incl. Abstract, Acknowledgement, the ToC itself, lists) + appendices
%%                 + reference list, each with page number. Depth = sub-section.
%%  LOF-01 AUTO    List of Figures (1.8, App. IV): "Figure 1.1  Title ...... page", header "Page".
%%  LOT-01 AUTO    List of Tables  (1.9, App. V):  "Table 1.1  Title ...... page", header "Page".
%%  ABB-01 AUTO/MANUAL  List of Abbreviations (1.10, App. VI): two columns (Abbreviation |
%%                 Description), ALPHABETICAL order (MANUAL), international standard
%%                 abbreviations, each explained at first use in the text (MANUAL).
%%  LOA-01 AUTO    List of Appendices (App. VII): Appendix | Description | Page.
%%
%%  --- BODY -------------------------------------------------------------------
%%  BDY-01 AUTO    Starts with Introduction; ends with Conclusions and Recommendations;
%%                 every chapter has a number and a title (1.11). Chapter numbers "1." etc.
%%  BDY-02 AUTO    Chapter 1 sub-sections: Background and Literature Survey; Research Gap;
%%                 Research Problem; Research Objectives (3).
%%  BDY-03 AUTO    Chapter 2 sub-sections: Methodology; Commercialization Aspects of the
%%                 Product; Testing and Implementation (3).
%%  BDY-04 AUTO    Chapter 3 sub-sections: Results; Research Findings; Discussion; Summary of
%%                 Each Student's Contribution (3; C3).
%%
%%  --- BACK MATTER ------------------------------------------------------------
%%  REF-01 AUTO/MANUAL  Reference List (1.12): APA or IEEE only (\CitationStyle); lists exactly
%%                 the sources cited in the text (MANUAL); entries single-spaced with ONE
%%                 BLANK LINE between entries; heading has NO chapter number but appears in
%%                 the ToC.
%%  BIB-01 AUTO    Bibliography optional (1.13) -> \IncludeBibliographytrue.
%%  GLO-01 AUTO    Glossary optional, 1-2 pages (3) -> \IncludeGlossarytrue.
%%  APP-01 AUTO    Appendices (1.14): heading "APPENDIX A: TITLE", ToC entry "Appendix A: Title",
%%                 page numbers continue in the same typeface/size; figures/tables numbered
%%                 A.1, B.1...; photocopied material must be letter quality (MANUAL).
%%
%% ============================================================================
%%  §C  AMBIGUITIES & CONFLICTS IN THE SOURCE GUIDELINE  (and the resolution used)
%% ============================================================================
%%  C1  Arabic page-number position. 2.03 says "centered at the right bottom"; the
%%      guideline's own pages show it centred. CHOSEN: bottom RIGHT (Roman numerals stay
%%      centred, which is the contrast the text draws). FLIP: \ArabicNumberCenteredtrue.
%%  C2  Order of preliminary pages differs between the two component lists and the sample
%%      ToC (Abstract vs Acknowledgement; Tables vs Figures). CHOSEN: Declaration,
%%      [Dedication], Abstract, Acknowledgement, ToC, Figures, Tables, Abbreviations,
%%      Appendices list (both numbered lists agree on Declaration/Abstract/Acknowledgement;
%%      Figures-before-Tables follows 1.7/1.8 and Appendices IV/V). FLIP: reorder blocks in §G.
%%  C3  "Summary of Each Student's Contribution" is a sub-section of Results & Discussion
%%      in list 1 (xii.4) but a stand-alone item (1.13) in list 2. CHOSEN: last sub-section
%%      of chapter 3 (3.4). FLIP: move it to its own \chapter before the conclusions.
%%  C4  Last chapter is called "Conclusion", "Conclusions" and "Conclusions and
%%      Recommendations" in different places. CHOSEN: "Conclusions and Recommendations"
%%      (matches the sample ToC and 1.11).
%%  C5  Sample captions read "Figure 1", but 1.8/1.9 require the chapter number and the
%%      sample lists show 1.1. CHOSEN: chapter-based "Figure 1.1" with a colon in captions.
%%  C6  "One and a half line spacing". CHOSEN: setspace \onehalfspacing (= 1.5 x font size,
%%      18 pt leading at 12 pt). Word's "1.5 lines" with Times New Roman is ~20.7 pt; for a
%%      Word-identical look replace \onehalfspacing with \setstretch{1.43} in §F.
%%  C7  "Times New Roman 11-point Light" (abstract). Times has no Light weight -> regular.
%%  C8  Abstract heading is Title Case 12 pt bold (1.4) while other front-matter headings
%%      follow the chapter style (ALL CAPS 14 pt bold, as in Appendices II, IV-VII).
%%  C9  NOT specified by the guideline, so chosen to match the sample pages: heading
%%      alignment = left; paragraphs = block style (no indent, 6 pt gap); caption alignment =
%%      centred; ToC dot leaders; ToC spacing = 1.5 (literal reading; if the ToC then exceeds
%%      2 pages set \TocSingleSpacedtrue); list/figure/table entry layout per Appendices IV-VII.
%%  C10 Margin diagrams in Appendices I/II are labelled inconsistently. Text rule 2.3 used.
%%  C11 Cover (App. I) and Title page (App. III) differ; cover = hard copy only (3.i).
%%  C12 Appendix I/III print "Sri Lanka Institute of" (truncated) -> full institute name.
%%  C13 Title page is not numbered AND not counted (Declaration = i, App. II).
%%  C14 "background literature" (3 list 1) vs "Background & Literature Survey" (1.10) ->
%%      "Background and Literature Survey".
%%  C15 Back-matter order: Reference List -> Bibliography -> Glossary -> Appendices.
%%  C16 Heading "References" (3) vs "Reference List" (1.12, App. II) -> "Reference List".
%%  C17 "Document Size: Min 50 A4 Pages" sits beside the Glossary line; interpreted as the
%%      size of the whole document.
%%
%% ============================================================================
%%  §D  WHAT LaTeX CANNOT ENFORCE  +  VIOLATION -> FIX RECIPES
%% ============================================================================
%%  MANUAL CHECKS (the AI must do these itself)
%%  M1  Heading case. \chapter{Title}: type normal Title Case (template upper-cases).
%%      \section{Title Case Like This}; \subsection{Sentence case like this}.
%%      Keep acronyms and proper nouns capitalised (e.g. "IoT", "Sri Lanka").
%%  M2  Abstract: count words (<= 300), check it states intro, method, tests, results,
%%      conclusions, recommendations; 3-5 keywords; fits one page.
%%  M3  Page budgets per chapter (DOC-04) and total >= 50 pages:  pdfinfo out.pdf | grep Pages
%%  M4  Each float is cited by number with \cref in the text before/near it; no "the
%%      following table/figure/above diagram".
%%  M5  Oversized tables/figures moved to appendices.
%%  M6  Photographs: sufficient resolution; no glossy/dark-background images where avoidable;
%%      add \OriginalInColor to the caption when in colour.
%%  M7  Abbreviations: spelled out at first use; list alphabetical; no abbreviation in the list
%%      that is unused (and vice-versa).
%%  M8  References: every \parencite key appears in the list, every listed work is cited; one
%%      style only (APA or IEEE). Use \parencite{key} for both styles.
%%  M9  Declaration: names/IDs match the title page; supervisor name filled; signatures are
%%      left blank for the humans to sign. Never fabricate signatures or dates.
%%  M10 Final copy free of typographical/grammatical errors (6.3).
%%  M11 Hard-bound copy: black cover, gold lettering, spine details (COV-02).
%%  M12 Embargo (1.3): if requested by candidate + supervisor, add a short embargo statement
%%      to the Declaration page.
%%  M13 Output verification:  pdffonts out.pdf  (Times-like fonts only);  pdfinfo out.pdf
%%      (page size 595 x 842 pt = A4);  pdftotext -layout out.pdf  and scan for "??"
%%      (unresolved references), "[TODO", "Sample".
%%
%%  VIOLATION -> FIX RECIPES   (V = "if you see ...", Fix = "do ...")
%%  V1  \documentclass[11pt|10pt|article|book|memoir|twoside]  -> report, a4paper,12pt,oneside.
%%  V2  \usepackage{geometry} / \geometry / \setlength{\oddsidemargin...} / fullpage / vmargin
%%      -> delete; margins are fixed in §F.
%%  V3  \linespread, \doublespacing, \singlespacing for body, \setstretch globally
%%      -> delete; spacing is fixed in §F. (Local \singlespacing is only legal inside quotes,
%%      tables, abstract, references - these are already automatic.)
%%  V4  \usepackage{times|palatino|helvet|lmodern|libertine|...}, \renewcommand{\rmdefault},
%%      \sffamily/\ttfamily for prose, \setmainfont  -> delete; fonts fixed in §F.
%%  V5  \usepackage{titlesec|sectsty|tocloft|fancyhdr|setspace|caption|hyperref|biblatex}
%%      configured differently -> delete the draft's copy; §F already configures them.
%%  V6  Fake headings (\textbf{Introduction}, \Large, \section*) -> real \chapter/\section/
%%      \subsection. Typed-in numbers ("1.2 Aims") -> remove the number.
%%  V7  \chapter{INTRODUCTION} (typed caps) -> \chapter{Introduction}.
%%  V8  \newpage / \clearpage / \pagebreak before chapters -> delete (automatic).
%%  V9  \maketitle, titlepage env, \author/\date/\title -> use §E macros (\sliitmaketitlepage).
%%  V10 \begin{abstract} (report class) -> sliitabstract environment + \sliitkeywords.
%%  V11 \tableofcontents / \listoffigures / \listoftables used directly, or hand-typed lists
%%      -> use \sliittoc, \sliitlistoffigures, \sliitlistoftables (they add ToC entries, the
%%      "Page" header and the correct formatting).
%%  V12 \pagestyle{headings|myheadings|plain}, \thispagestyle{plain}, \pagenumbering{...}
%%      in the body, \setcounter{page}{...} -> delete (automatic: §G switches at the right
%%      places).
%%  V13 \includegraphics outside a float, \begin{center}...\end{center} around figures ->
%%      figure env (see sample); caption below. Table caption ABOVE the tabular.
%%  V14 Hand-typed "Figure 3:", "Table 2", "see above/below" -> \caption + \label + \cref.
%%  V15 "the following table", "the figure below" -> \cref{...} citing the number.
%%  V16 \begin{table} with \linespread/double spacing or \Large -> remove; table style is automatic.
%%  V17 \begin{thebibliography}, natbib/\bibliographystyle, \cite -> .bib file + \addbibresource,
%%      \parencite; heading via \sliitprintreferences.  "References" chapter with a number
%%      -> \sliitprintreferences (unnumbered, "Reference List").
%%  V18 Appendices written as \chapter{Appendix A...} or \section{Appendix ...} ->
%%      \sliitbeginappendices once, then \sliitappendix{Title} per appendix.
%%  V19 \begin{quote} with double spacing / font changes -> plain quote env (spacing automatic).
%%  V20 Coloured text/links (colorlinks, \textcolor) -> remove (print document); gold is
%%      reserved for the hard cover.
%%  V21 \vspace / \\\\ / empty lines used to create vertical space between paragraphs ->
%%      delete (paragraph spacing is automatic).
%%  V22 \footnote-heavy or \subsubsection structure -> flatten to the three allowed levels
%%      (FNT-07) or convert to run-in text / lists.
%%

\begin{sliitabstract}                                                                 % [ABS-01] <= 300 words
  Large language models (LLMs) are increasingly used to translate
  natural-language security requests into machine-executable tool actions, but
  their stochastic output---malformed schemas, hallucinated parameters,
  out-of-scope targets and adversarial phrasing---makes them unsafe to feed
  directly to automated security tooling. This dissertation designs, implements
  and evaluates NeuroShell IRE, a guarded intent-recognition engine that
  constrains the raw output of a small, offline, CPU-only language model with
  deterministic validation before any downstream dispatch.

  The methodology is a controlled design-and-evaluation study under a committed
  protocol: a purpose-built synthetic data set of 1,500 security prompts (600
  well-formed, 900 flawed across eight flaw classes) is scored through a
  seven-stage pipeline wrapped in five middleware components, using two offline
  backends (Gemma and Qwen) under four experiments measuring pipeline value,
  backend head-to-head, per-layer ablation and per-class catch. On the
  evaluated records, the guarded pipeline raises decision accuracy from
  69--78\% to 82--86\%, raises the flaw-catch rate from 0\% to 64--72\%, and
  lowers the false-positive rate from 31--32\% to 14--15\%. Ablations show the
  deterministic validation stack is the dominant safety contributor: removing
  it reduces the catch rate by 30 and 24 points respectively, and removing the
  hallucination validator alone by 9 and 14 points; the catch-rate ordering is
  reproduced across both backends.

  The dissertation concludes that a small offline model can be made reliable
  enough to gate an automated security copilot provided the trust boundary
  remains closed (retrieval-free, with no free-form output rendered
  downstream). Because the evaluation consists of single-run point estimates on
  a synthetic, non-uniform data set on a single device, external validity is
  bounded. Future work should remove the single-run limitation, strengthen the
  weakly protected semantic flaw classes, and close the verified engineering
  gaps---default development credentials and the inactive \texttt{production}
  scope mode---before any deployment.
  \sliitkeywords{Intent Recognition, LLM Guardrails, Hallucination Detection, Offline Language Models, Security Copilots}
\end{sliitabstract}
