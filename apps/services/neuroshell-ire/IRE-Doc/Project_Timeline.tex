\section{Project Timeline}

\textbf{NeuroShell Core Framework (R26-CS-018) --- MSc Cybersecurity Research Project}

This document is the weekly project timeline for the NeuroShell Core Framework, covering all four components as a single system:

\begin{itemize}
\item \textbf{Component 01 --- Intent Recognition Engine (IRE):} NLU gateway converting natural-language operator commands into validated JSON intent contracts.
\item \textbf{Component 02 --- Dynamic Planner RAG Engine:} Retrieval-Augmented Generation planner producing ordered execution graphs and success probabilities.
\item \textbf{Component 03 --- Adaptive Execution and Error Recovery Engine (AEERE):} Self-healing runtime engine categorizing errors and executing recovery strategies.
\item \textbf{Component 04 --- AI Vulnerability Analysis Engine (AVAE):} Scans, parses, enriches (NVD / CISA KEV / FIRST EPSS), predicts exploitability (XGBoost + SHAP) and triages vulnerability findings.
\end{itemize}

\section{3. MS Teams Planner Usage}

The companion file \texttt{MS\_\allowbreak Teams\_\allowbreak Planner\_\allowbreak Import.\allowbreak csv} contains one row per weekly task plus the milestone tasks, ready for import into Microsoft Teams Planner. Columns are: Task Name, Bucket Name, Start Date, Due Date, Progress, Priority, Notes.

\begin{itemize}
\item \textbf{Buckets} group the plan into Proposal, Phase A Foundations, Phase B Implementation, Phase C Progress 2 and Docs, Phase D Thesis and Website, Phase E Final and Viva, Phase F Publication.
\item \textbf{Progress} uses Completed (2026-03-15 to 2026-09-05) and Not started (2026-09-06 onwards); switch each task to In progress / Done as work is completed each week.
\item \textbf{Assignees} can be added in Planner per component owner (C1: IRE, C2: Planner, C3: AEERE, C4: AVAE).
\end{itemize}
